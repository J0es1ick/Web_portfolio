# J0es1ick — портфолио разработчика

Личное портфолио в виде портативной консоли в стиле Game Boy. На зелёном экране — профиль, проекты, стек, опыт и контакты; разделами можно управлять кнопками на корпусе или с клавиатуры. Переключатель питания запускает и выключает экран, а крестовина наклоняется в сторону нажатия.

Сайт написан на HTML, CSS и JavaScript без сторонних npm-зависимостей. Без JavaScript содержимое остаётся доступным на одной странице.

## Локальный запуск

Нужен Node.js 18 или новее. Устанавливать пакеты не требуется.

```sh
npm run dev
```

Откройте [локальную страницу](http://127.0.0.1:4173). Сервер отдаёт только файлы сайта и его ресурсы.

## Управление

| Элемент | Действие |
| --- | --- |
| Вкладки на экране | Открывают профиль, проекты, стек, опыт или контакты |
| Крестовина ← / → | Переключает разделы по кругу |
| Крестовина ↑ / ↓ | Прокручивает содержимое экрана |
| A | Выполняет действие, указанное рядом с кнопкой: открывает проекты, репозиторий или контакт |
| B | Возвращает к профилю |
| SELECT | Открывает следующий раздел |
| START | Открывает проекты |
| OFF / ON | Выключает и включает экран с восстановлением выбранного раздела |
| FX | Включает и выключает анимацию экрана |

На клавиатуре работают стрелки, **A / Ф** и **B / И**. Когда фокус находится на вкладках или переключателе проектов, стрелки управляют именно ими; **Home / End** переходят к первому или последнему элементу. Проекты также можно выбирать кнопками «Назад» и «Вперёд» внутри экрана.

Кнопки браузера «Назад» и «Вперёд» восстанавливают выбранный раздел и проект. Прямые ссылки с фрагментами `#scheduler`, `#game`, `#skills` и `#contact` ведут к соответствующему содержимому.

Длинные разделы прокручиваются внутри экрана. Интерфейс поддерживает управление с клавиатуры и программы экранного доступа, а системная настройка уменьшения движения отключает эффекты. Пока питание выключено или экран запускается, экранные вкладки и кнопки управления блокируются; переключатель питания остаётся доступным.

## Проекты

- [Scheduler](https://github.com/J0es1ick/Scheduler) — платформа расписаний вузов: Telegram-бот, публичный сайт и панель управления источниками.
- [Shortli](https://github.com/J0es1ick/Shortli) — сервис коротких ссылок для самостоятельного размещения, с аналитикой, QR-кодами и API.
- [Пыль и Корона](https://github.com/J0es1ick/Game) — одиночная браузерная RPG с постоянным миром и локальными сохранениями. [Играть](https://j0es1ick.github.io/Game/).
- [Go Load Balancer](https://github.com/J0es1ick/load_balancer) — обратный HTTP-прокси с управлением серверами, проверками доступности и мониторингом. [Интерактивное демо](https://j0es1ick.github.io/load_balancer/).
- [Resplitter](https://github.com/J0es1ick/Resplitter) — командный проект для разделения ресторанного счёта через Telegram и распознавание чеков.
- [Reminder](https://github.com/J0es1ick/Reminder) — Telegram-бот с личными напоминаниями и прогнозом погоды.

## Сборка и проверка

```sh
npm run build
npm test
```

Сборка копирует сайт в `dist/`. Тесты проверяют навигацию, прямые ссылки, восстановление состояния, переключение питания и связи элементов в HTML.

Для публикации подойдёт любой статический хостинг. На GitHub Pages можно разместить как содержимое `dist/`, так и исходные файлы из корня репозитория: пути к ресурсам относительные.

## Структура

- `index.html` — содержимое, ссылки и метаданные страницы.
- `styles.css` — оформление, адаптивная вёрстка и поддержка уменьшения движения.
- `console.css` — корпус консоли, экран, кнопки и переходы питания.
- `script.js` — взаимодействие с интерфейсом, фокус, история браузера и анимация.
- `player-state.js` — состояние навигации и обработка фрагментов URL.
- `power-state.js` — переходы включения и выключения экрана.
- `assets/` — изображения и значок сайта.
- `scripts/` — локальный сервер, сборка и тесты.

Шрифты Golos Text, JetBrains Mono и Russo One загружаются из Google Fonts; при недоступности используются системные шрифты. На сайте нет аналитики, трекеров, API-ключей или запросов к GitHub во время работы.
